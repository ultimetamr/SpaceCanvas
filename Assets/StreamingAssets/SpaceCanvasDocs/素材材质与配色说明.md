# 素材材质与配色说明

## 默认外观

素材库新增物体与导入工程使用同一素材工厂。已接入的精选模型保留原贴图；其余家具、电子设备、厨房与展陈素材使用按部件分配的 URP PBR 配色。基础几何体采用中性的默认材质。

程序化素材的共享材质位于 `Assets/Resources/SpaceCanvasMaterials/Finishes/`：Timber、Graphite、Steel、Fabric、Linen、Ceramic、Leaf、Screen、Brass、Paper。这些是基础配色与 PBR 参数，不是扫描模型或木纹、布纹贴图。

餐椅包含布面与木质椅脚；显示器包含机身与屏幕；键盘区分机身与键帽；书本区分封面与纸页。列表缩略图由同一个素材工厂生成。

## 工程参数

JSON 的 `colorHex` 仍作为物体颜色参数保存。程序化家具把该颜色与素材部件原色相乘，因此 `#FFFFFFFF` 表示保留原有部件配色。精选模型继续使用既有的轻量染色强度，避免覆盖贴图。基础几何体直接使用指定颜色。

`metallic` 对有原生金属材质的部件使用原始值与用户值中的较大者；`alpha` 乘以原始透明度。部件光滑度由素材材质提供。导出不会把物体的多个部件合并为单一材质，重新导入时按 `assetId` 恢复相同部件并应用工程参数。

## 扩展与排查

可替换 Finishes 中的材质，或提供同名精选 prefab 以接入带真实贴图的模型。请使用与当前 URP 管线兼容的 shader，并保留材质与贴图的序列化引用。修改程序化素材后应更新 `SpaceCanvasPremiumAssetTag.CurrentRevision`，以便工作台迁移旧实例。

各可编辑物体只修改自己的材质克隆。隐藏导入层级同样建立克隆；开发版审计只释放自身创建的克隆，不销毁 Resources 共享材质。

Development Build 启动后在 `Application.persistentDataPath/MaterialAudit.txt` 输出 36 个素材的 shader 支持情况、材质槽数、非白色槽数和贴图槽数。该检查不能替代真机目视检查。
