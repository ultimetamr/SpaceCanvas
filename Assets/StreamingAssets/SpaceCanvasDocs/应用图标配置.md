# SpaceCanvas 应用图标

图标采用与应用一致的灰金配色和空间画布符号。源文件位于 `Assets/Scripts/ProjectIO/Editor/Branding/`：

- `SpaceCanvasIcon.png`：1024 × 1024 完整图标，用于默认图标与 APK 备用 PNG。
- `SpaceCanvasBackground.png`：不透明自适应背景。
- `SpaceCanvasForeground.png`：透明自适应前景，主要图形保留在中央安全区域。

`SpaceCanvasAppIcon` 通过 Unity 官方构建回调设置 Android 自适应图标。Unity 6.6 已移除 Legacy/Round 图标配置 API，但生成的 launcher 工程仍带有 Unity 默认备用 PNG；因此通过官方 Gradle 工程回调替换 `launcher/src/main/res/mipmap-mdpi/app_icon.png`。无需修改 SDK 或最终签名 APK。

如需更换品牌图，替换上述三个 PNG 后重新构建。构建时会检查资源并重新配置图标。

2026-11-06 验证：构建成功，0 错误；APK 签名验证通过。从 APK 提取的自适应前景、背景和备用 PNG 均已人工核对为 SpaceCanvas 图标。已覆盖安装到 Swan，保留应用数据。构建日志为 `Logs/Unity6-AppIcon-Build.log`，安装记录为 `Logs/Unity6-AppIcon-Installed.json`。
