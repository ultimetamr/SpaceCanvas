# 工作空间视角与旋转

0.3.3 新增底部「视角」控制条，位于物体编辑工具上方。使用现有手柄射线或手势点击。

- **左转 / 右转**：每次绕工程竖轴旋转 45°，可连续旋转一整圈，检查模型背面与遮挡处。
- **正面 / 侧面 / 背面 / 俯视**：切换整个工程的查看方向。俯视为 90°，内容适当缩小并上移以避开底部工具条；在俯视下点击左转或右转会回到直立视图。
- **复位**：恢复当前工作台内的默认查看方向，保留距离、高度和工作台大小。
- 原有 **回正**：同时恢复默认查看方向，并按当前头部朝向重新放置整套工作台及面板。

视角切换平滑过渡约 0.3 秒。切换会取消尚未确认的放置预览、结束进行中的编辑事务；过渡结束后继续编辑，避免转动中的坐标系带动物体误位移。半透明预览和编辑手柄跟随工程平面与局部轴线。

## 数据与二次开发

`SpaceCanvasWorkspaceView` 仅修改 `SpaceCanvasWorkspace.contentRoot` 的查看变换（旋转，以及俯视时的容器缩放、偏移）。它不旋转 XR 相机或工具面板，也不改写工程根节点及其物体的局部位置、四元数和缩放。

旋转中心为工程坐标原点。JSON 继续采用原有米制工程坐标；保存、恢复与撤销均不包含查看方向，导入 Unity 后不会把观察角度误当成物体变换。单次旋转不占用 20 步编辑撤销栈，使用「复位」恢复查看方向。

已有 MR 场景由 `SpaceCanvasWorkspace.Awake` 自动初始化；标准 Android 构建入口 `SpaceCanvasFullSpaceBuilder.BuildExistingAndroid` 会为已保存场景补齐视角控制条及 XR UI 射线组件，不重建原有模型或布局。

公开接口：`Turn(float degrees)`、`Show(Preset preset, bool animate = true)`、`ResetView()`。自定义视角界面应调用这些接口，避免直接改写物体 Transform。过渡期间 `InputBlocked` 用于阻止新拖动和新放置操作。

## 验证清单

EditMode 测试覆盖：四种视角不改变 JSON、完整一周与复位不累积漂移、旋转后的工程导入与撤销、俯视下局部坐标拖动、俯视下半透明预览与落点一致、取消预览、重复绑定不重复执行按钮，以及按钮边界。

真机仍需检查：控制条文字清晰且不遮挡模型、所有视角平滑、旋转后射线选取与拖动、俯视放置、保存后 Unity 还原的布局一致。自动化结果不能替代这些视觉与输入验收。
