# 新手教学

> 菜单已精简：默认仅显示“导入PICO工程 > 导入工程文件”。本文提及的 Tools > SpaceCanvas 开发菜单仅在启用 SPACECANVAS_DEVELOPER_MENUS 编译符号后显示；底层构建、验收和修复方法仍保留。

当前 Full Space MR 工作台内置首次启动教学：射线点击 → 添加素材 → 调整物体 → 保存工程 → 查看官方模板 → 完成。手柄扳机和已启用的手势捏合共用现有 XR 输入链路。

- 教学提示位于固定工作台上方，不绑定头部，不自动替换作品。弹窗打开时提示隐藏，关闭后恢复。
- 添加成功、实际提交位姿修改、保存成功、打开官方示例分页分别推进对应步骤。无变化点击、取消手势、保存失败不会误推进。
- 每一步均可跳过，也可随时结束。结束或完成后记录 PlayerPrefs `SpaceCanvas.Onboarding.Seen.v1`，下次启动不再自动出现。未结束便退出应用，下次从欢迎页开始。
- 工具栏末尾 `?` 可重新开始。教学重播只重置教学，不清空场景或撤销记录。
- 查看模板无需导入；真正替换场景仍走原有确认与整次导入撤销流程。教学不强迫用户执行破坏性操作。

## 开发接入

`SpaceCanvasTutorialFlow` 只负责有序状态；`SpaceCanvasOnboarding` 负责 UI、首次启动记录和成功事件订阅。事件源分别在 WorkspaceUI、EditSession、ProjectIOUI。XR Presentation 在教学切页时消费当前按压，防止一次点击触发新页面。

通过 Tools > SpaceCanvas > 重建 MR 界面与射线 保存场景配置，教学嵌套 Canvas 与其他界面统一安装 TrackedDeviceGraphicRaycaster。更换 Canvas 后须执行此菜单；无需新增 PICO API 或第三方包。

修改教学内容时同步维护标题、说明与步骤枚举，并重新执行字体构建。若需要新版本再次首次展示，可提升 SeenPreference 的版本后缀；请勿清除其他用户偏好或工程文件。
