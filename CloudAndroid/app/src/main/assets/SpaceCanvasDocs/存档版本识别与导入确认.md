# 存档版本识别与导入确认

本次改进用于减少选错保存版本、导入后无法辨认来源的问题，保持现有 Full Space MR 工作台与素材系统。

## 头显端

- 保存时从实际可编辑模型生成 320×200 缩略图，作为可选 PNG/Base64 字段随 JSON 文件保存。不会截取现实环境或 UI。
- 本地工程列表显示文件名、保存时间、物体数量和文件指纹，按工程内保存时间倒序排列，最新有效条目标记“最新”。同一秒多次保存按毫秒排序。
- 点击版本先显示确认卡；确认卡和实际导入使用同一份已读取数据，源文件期间变化不会导致偷偷导入另一份内容。
- 保留取消、保存并导入、备份并导入，以及整次导入撤销。损坏文件仍可看到，但不会进入导入。
- 预览和保存毫秒时间属于保存元数据，不参与作品脏状态和忽略时间的内容比较。

## Unity 编辑器端

入口仍为 `导入PICO工程 > 导入工程文件`。读取头显文件后打开版本列表，选择条目不会创建对象，须核对详情并点击“确认导入此版本”。窗口显示电脑副本完整路径，支持选择本地文件及刷新目录。

列表优先使用 JSON 保存时间，避免 ADB 复制时间造成误判；缺少保存时间的旧文件用文件时间并明确标注。指纹为实际字节 SHA-256 的前 8 位，仅用于快速识别。

独立导入器继续放在同一个 `SpaceCanvasEditorImporter.cs` 文件中，无须引用 SpaceCanvas 运行时业务程序集。模型一致性仍依赖配套素材资源；JSON 缩略图不会变成模型资源。

## 兼容与边界

- 旧存档可直接导入；没有图时显示“暂无预览”。更新应用后重新保存才能补图，旧文件不会被修改。
- PNG 不超过 256 KB，解码前检查签名及不超过 1024×1024 的尺寸。坏图只禁用预览，不阻断合法布局。
- 版本读取限制单文件 16 MB。超限或损坏文件提供中文提示。
- 时间来自保存设备时钟，在当前设备本地时区显示；时钟不准时同时核对文件名、模型图和文件指纹。
- 本地列表展示读取时快照，重新打开列表或刷新编辑器目录后读取文件变化。
