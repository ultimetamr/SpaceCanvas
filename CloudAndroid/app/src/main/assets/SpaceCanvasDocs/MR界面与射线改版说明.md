# MR 界面与射线改版（2026-10-29）

> 菜单已精简：默认仅显示“导入PICO工程 > 导入工程文件”。本文提及的 Tools > SpaceCanvas 开发菜单仅在启用 SPACECANVAS_DEVELOPER_MENUS 编译符号后显示；底层构建、验收和修复方法仍保留。

本次修改基于现有 Full Space MR 场景，保留 JSON 导入、导出与 20 步撤销功能。仅只读参考 my-pico-unity-app 的射线交互代码，未修改该参考工程。

## 可见变化

- 素材库、属性面板、工具栏分别使用独立的世界空间 Canvas，取消共面的大片覆盖层；中心区域留给场景模型。
- 素材库提供分类与每页六个素材卡片，支持手柄/手势直接点击翻页。
- 底部显示当前编辑工具；“专注编辑”收起两侧面板，“展开面板”恢复；“回正”在当前视野前重新放置工作台。
- 保存/导入/关于开源/撤销集中在紧凑底栏。导入选择、确认与关于面板互斥；打开弹窗时侧栏淡出且停止接收点击，禁止编辑背后物体。
- 不透明弹窗背景保证文字不会被模型干扰；圆角使用 uGUI 网格生成，无额外图像插件。

## 射线与输入

SpaceCanvasRayInteractor 使用 XRI 的 clickOnDown，使普通按钮在按下时响应；拖动控件仍交由 XRI 处理。SpaceCanvasPointerVisual 绘制最多 3 米的细青色射线，遇到可操作目标变为琥珀色、按下为绿色，并显示小目标环。射线终点遵循较近的 UI/物理命中。

控制器扳机使用 0.75/0.55 阈值迟滞；手势优先使用官方 HandInteractionProfile 的 pointerActivated。原生激活结束时，不让持续的 pinchValue 维持按下状态。切换弹窗消耗当前按压，必须释放再按才能点击下一页；丢失追踪取消手势并释放 UI。

## 维护与验证

Tools > SpaceCanvas > 重建 MR 界面与射线 显式更新 Full Space 场景中的 UI 和输入组件。该操作会重建界面；正常构建保留已有布局。Tools > SpaceCanvas > 测试 > 渲染 MR 布局预览 输出 Library/MRPreview 下的三张实际 Unity 场景渲染，供检查布局，不代表头显截图。

本轮 20 项真实 Unity EditMode 测试通过、失败 0，包含手腕设备过滤、追踪丢失释放与原生手势释放回归。Android 构建通过，错误 0；构建警告原样保存在诊断文件中。新布局和射线需在重新连接的真机上继续确认。旧版用户确认的“关于开源可打开”“官方示例可导入”不等同于新版手感已验收。

当前仍为 PICO OpenXR Full Space + 透视 + Unity uGUI，未实现 Shared Space 系统多窗口、系统输入弹窗或眼动输入。不能据此承诺评审五星。
