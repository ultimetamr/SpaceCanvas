# SpaceCanvas 编辑体验与恢复优化

更新日期：2026-10-30。运行入口保持 Full Space MR、PICO 透视与 Unity 世界空间 Canvas。

## 素材放置

点击素材缩略图后出现半透明预览。射线可落在工程地面，或已有物体朝上的碰撞表面；再次按扳机或捏合才创建物体。支持取消、追踪丢失隐藏、双手指针租约、忽略 UI 点击和导入时取消预览。这里的“地面/桌面”指工程中的虚拟几何，不宣称已识别真实房间平面。

预览根不在 ContentRoot 内，碰撞体关闭且置于 IgnoreRaycast 层，因此不参与保存和撤销。确认后按真实 Mesh bounds 的底部落地，兼容中心轴心与底部轴心，不强行修改旧工程坐标或素材尺寸。当前放置朝向使用素材默认朝向；确认后可用旋转工具调整。

## 精准编辑

- 工具栏与属性面板的“位置、旋转、尺寸”同步。
- X/Y/Z 按钮限制手势移动或旋转的父节点局部轴；“自由轴向”解除约束。
- 吸附启用时，移动步长为 0.25 m，旋转为 15°，手势等比缩放以 0.1 倍步进。
- 属性加减步长：位置 0.05 m、旋转 15°、尺寸 0.1 倍；尺寸调整保持原有比例。
- 透明度、金属度改用 0–1 滑条，连续拖动只创建一个撤销事务；保存、切换选择、导入与失去面板时先结束事务。
- 选择框使用缓存后的 Mesh 局部边界，不再每帧申请 Renderer 数组；RGB 轴用于辨认方向，轴线本身不是可抓取的控制柄。
- 已有精细模型和分部位配色保持不变；36 个素材的边界、碰撞体和 PBR 材质纳入自动检查。
- 关闭碰撞体只关闭物理碰撞，不锁定编辑。装饰画、地毯等仍可用射线选取和拖动，保留原始 JSON 的 `colliderEnabled=false`。编辑命中使用物体局部 Mesh 边界，遵守前景物理遮挡；不启用隐藏碰撞体。自定义脚本改变内部网格或子模型姿态后，调用 `InvalidatePickingBounds()` 刷新边界缓存。

## 保存、恢复与导入保护

- 手动工程仍写入 `Application.persistentDataPath/Projects/*.spacecanvas`，同名追加序号。
- 未保存作品每 30 秒写入 `persistentDataPath/Recovery/recovery-0.json` 或 `recovery-1.json`。先写临时文件、刷新到存储、重新解析校验，再替换较旧槽位。最新槽损坏时尝试另一槽。
- 回到后台或退出时尽力补写；突然断电/进程强杀只保证最后一次完整写入，不能承诺恢复最后 30 秒内的全部操作。
- 启动发现副本会询问“恢复作品、稍后恢复、丢弃副本”，不会自动替换作品；稍后可从“布局 → 恢复上次作品”重新打开。待处理副本不会被新自动备份覆盖。
- 导入前发现未保存修改，会另存 `Projects/恢复备份_*.spacecanvas`。备份失败时暂停导入。也可点击“保存并导入”；保存失败时保留当前确认面板。
- 导入和恢复各占一个撤销步骤；不会删除用户的手动保存文件。恢复备份可在本地工程页重新打开。
- 工具栏状态约每 2 秒更新，捕获时间变化不视为编辑；外部脚本改变坐标、颜色、碰撞体等同样可被检测。

## 舒适布局

“布局”中可调距离 1.2–2.2 m、高度相对头部 -0.5–0.3 m、工作台显示大小 65–135%。点击“应用并回正”后平滑过渡并记忆偏好。启动时依照新的有效追踪姿态定位，不使用上次会话的绝对世界坐标。工作台不绑定头部，也不会随每次转头移动。显示大小只作用于工作台锚点，JSON 局部尺寸保持不变。

## 诊断与性能口径

`SpaceCanvasPerformanceMonitor` 在前台记录最多 5400 帧的 Unity 帧间隔，在前台采样满 60 秒后自动导出一次，也可在“布局 → 导出运行诊断”手动导出。文件位于 `persistentDataPath/Diagnostics/`。记录均值、P50/P95/P99、最大帧间隔、Unity 分配/保留内存、会话 GC 次数及物体数量范围；XRStats 支持时另记 GPU 时间。

Unity 帧间隔包含等待时间，不等于 GPU 耗时、系统合成器 FPS 或 PICO 官方帧流水线指标。Editor 的 100 物体导入/导出/撤销测试只证明数据正确性及编辑器耗时，不作为头显性能证据。性能结论必须基于实际设备报告；需要分析原生掉帧原因时另采 Perfetto。

眼动设备发现采用退避，要求有效且已追踪的完整姿态，不把头部方向伪装成眼动。手柄/手势射线可用时让出 UI 悬停。SDK/ROM 内部眼动报错不通过屏蔽日志伪装成修复。

## 二次开发文件

- `SpaceCanvasGeometry`：边界与落地。
- `SpaceCanvasPicking`：物理碰撞与编辑选取分离，射线点击和悬停反馈共用。
- `SpaceCanvasPlacement`：预览及确认，不依赖 PICO。
- `SpaceCanvasEditSession`：手势与约束事务。
- `SpaceCanvasScalarSlider`：滑条事务。
- `SpaceCanvasRecoveryStore`、`SpaceCanvasProjectSession`：恢复存储与场景会话。
- `SpaceCanvasWorkspaceSettingsUI`：舒适设置及持久化偏好。
- `SpaceCanvasPerformanceMonitor`：有界采样和运行报告。
- `Editor/SpaceCanvasStandaloneVerification.cs`：空 Unity 工程恢复验证工具，不引用运行时、PICO 或测试框架。
